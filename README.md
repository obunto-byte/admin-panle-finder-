# XEBAC HAT - Web Security Auditor 🔍

A powerful, multi-threaded vulnerability scanner designed to detect exposed administrative panels and sensitive backup files on web servers.

## 🚀 Features
- **Admin Panel Discovery**: Rapidly scans for common admin login paths (`/admin`, `/wp-admin`, etc.).
- **Backup File Exposure**: Detects publicly accessible database dumps and archive files (`backup.zip`, `db.sql`).
- **High Performance**: Uses Python's `ThreadPoolExecutor` for lightning-fast concurrent scanning.
- **Automated Reporting**: Generates detailed `JSON` and `TXT` reports for easy analysis.
- **Terminal UI**: Beautiful, color-coded terminal output for real-time feedback.
